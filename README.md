# منصة امتحان نظريات التأثير الإعلامي

منصة امتحانات تفاعلية باللغة العربية (RTL) مبنية على بنك أسئلة من **100 سؤال** في مادة *نظريات التأثير الإعلامي: الأسس والمفاهيم والتطبيقات* — تمهيدي ماجستير الصحافة الإخبارية.

🔗 **الموقع المنشور:** https://m0kama1.github.io/media-theories-exam/

## بنك الأسئلة (الإصدار الثاني)

100 سؤال أُعيد بناؤها من كتاب المادة «نظريات التأثير الإعلامي: الأسس والمفاهيم والتطبيقات» (إعداد محمد كمال عبدالله، إشراف أ.د. محمد زين)، موزعة على ستة محاور:

| المحور | عدد الأسئلة |
|---|---|
| المفاهيم الأساسية (التأثير ومستوياته وأبعاده وتطور تصوراته، أهمية النظريات) | 11 |
| الفصل الثاني: الوظائف والبينية والمنطلقات الكمية والكيفية | 17 |
| النظريات العشرون | 20 |
| النظريات والمداخل الإحدى عشرة | 20 |
| المقارنات بين النظريات المتشابهة | 12 |
| التطبيقات البحثية (اختيار النظرية الأنسب لعنوان دراسة) | 20 |

المستويات المعرفية: فهم 22 · تطبيق 48 · تحليل 30. لكل سؤال ملاحظة تعليمية قصيرة (سطر أو سطرين) تشرح سبب صحة الإجابة وتميزها عن أقرب اختيار خاطئ، مع موضع المرجع في الكتاب.

## المزايا

- امتحان واحد من 100 سؤال، مع ترتيب عشوائي للأسئلة والاختيارات في كل محاولة ودون تكرار.
- سؤال واحد في كل شاشة، السابق/التالي، وضع علامة، لوحة تنقل، شريط تقدم، ومؤقت اختياري.
- حفظ تلقائي للإجابات والترتيب في المتصفح، ورسالة تأكيد قبل التسليم.
- لا تظهر أي إجابة أو ملاحظة أثناء الحل.
- بعد التسليم: الدرجة والنسبة، وتحليل الأداء حسب المحور والفصل والمستوى المعرفي والنظرية، ومراجعة كل سؤال (إجابتك، الإجابة الصحيحة، الملاحظة التعليمية، المرجع) مع تصفية الصحيحة/الخاطئة/المتروكة، وطباعة أو حفظ PDF.
- وضع ليلي/نهاري، ودعم كامل للعربية RTL على الموبايل والكمبيوتر.

## التقنيات
React 18 · TypeScript · Tailwind CSS v4 · Vite · Vitest + Testing Library. موقع ثابت بالكامل بلا Backend ولا مفاتيح API.

## التشغيل والتطوير

```bash
npm install
npm run dev        # خادم التطوير
npm test           # تشغيل الاختبارات
npm run build      # بناء نسخة الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
```

> قيمة `base` في `vite.config.ts` مضبوطة على `/media-theories-exam/` لتطابق اسم المستودع على GitHub Pages. غيّرها إذا غيّرت اسم المستودع.

## بنية المشروع

```
src/
  data/questions.json    # بنك الأسئلة: السؤال، الاختيارات، الإجابة، الملاحظة التعليمية، المرجع في الكتاب
  lib/                   # منطق البنك والتصحيح والتحليلات والحفظ والتوجيه
  components/            # مكونات الواجهة المشتركة
  views/                 # الصفحات: الرئيسية، الامتحان، النتائج والمراجعة
  test/                  # اختبارات البيانات والمنطق والحفظ وتدفق الواجهة
```

## الاختبارات
- سلامة البنك: 100 سؤال بلا تكرار، 4 اختيارات مختلفة، إجابة صحيحة واحدة، ملاحظة قصيرة ومرجع لكل سؤال، وتغطية الفصول والمحاور والنظريات الإحدى والثلاثين.
- الترتيب العشوائي: كل امتحان يضم الأسئلة الـ100 مرة واحدة، والإجابة الصحيحة تبقى صحيحة أيًّا كان موضعها.
- الحفظ المحلي، والتصحيح والتحليلات، وتدفق الواجهة حتى المراجعة، والتسليم التلقائي بالمؤقت.

## النشر
يُبنى الموقع ويُنشر تلقائيًا على GitHub Pages عبر `.github/workflows/deploy.yml` عند كل Push إلى فرع `main` (بعد نجاح الاختبارات).

# منصة امتحان نظريات التأثير الإعلامي

منصة امتحانات تفاعلية باللغة العربية (RTL) مبنية على بنك أسئلة من **100 سؤال** في مادة *نظريات التأثير الإعلامي: الأسس والمفاهيم والتطبيقات* — تمهيدي ماجستير الصحافة الإخبارية.

🔗 **الموقع المنشور:** https://m0kama1.github.io/media-theories-exam/

## المزايا

**امتحان واحد من 100 سؤال**
- ترتيب الأسئلة **والاختيارات** عشوائي في كل محاولة جديدة، مع الحفاظ على ربط الإجابة الصحيحة بالتفسير.
- سؤال واحد في كل شاشة، أزرار السابق/التالي، ووضع علامة للعودة.
- لوحة تنقل بحالة كل سؤال (مُجاب / متبقٍّ / مُعلَّم) وشريط تقدم.
- مؤقت اختياري مع تسليم تلقائي عند انتهاء الوقت.
- حفظ تلقائي للإجابات والترتيب في المتصفح حتى بعد إغلاق الصفحة.
- رسالة تأكيد قبل التسليم، ولا تظهر أي إجابة أو ملاحظة أثناء الحل.

**النتائج والمراجعة**
- الدرجة والنسبة وعدد الصحيح/الخاطئ/المتروك، ورسوم بيانية حسب الفصل والصعوبة والنظرية.
- لكل سؤال: إجابتك، والإجابة الصحيحة، و**ملاحظة تعليمية مختصرة** (لماذا هي الصحيحة، ولماذا اختيارك خطأ إن كان كذلك، ومفتاح للتذكر)، مع تفسير بنك الأسئلة.
- تصفية المراجعة: الكل / الخاطئة / المتروكة / الصحيحة، وطباعة التقرير أو حفظه PDF.

**التصميم:** وضع ليلي/نهاري، متجاوب مع الموبايل، خط IBM Plex Sans Arabic مستضاف ذاتيًا.

## التقنيات
React 18 · TypeScript · Tailwind CSS v4 · Vite · Vitest + Testing Library. موقع ثابت بالكامل بلا Backend ولا مفاتيح API.

## التشغيل والتطوير

```bash
npm install
npm run dev        # خادم التطوير
npm test           # تشغيل الاختبارات
npm run build      # بناء نسخة الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
```

> قيمة `base` في `vite.config.ts` مضبوطة على `/media-theories-exam/` لتطابق اسم المستودع على GitHub Pages. غيّرها إذا غيّرت اسم المستودع.

## بنية المشروع

```
src/
  data/questions.json    # بنك الأسئلة الأصلي (دون تعديل – محمي ببصمة SHA-256 في الاختبارات)
  data/notes.ts          # الملاحظات التعليمية (منفصلة عن بنك الأسئلة)
  lib/                   # منطق البنك والتصحيح والتحليلات والحفظ والتوجيه
  components/            # مكونات الواجهة المشتركة
  views/                 # الصفحات: الرئيسية، الامتحان، النتائج والمراجعة
  test/                  # اختبارات البيانات والمنطق والحفظ وتدفق الواجهة
docs/media_theories_exam_100.md  # النسخة المرجعية لمفتاح الإجابة
```

## الاختبارات
- سلامة البيانات: 100 سؤال، 4 اختيارات غير مكررة، إجابة صحيحة واحدة، تطابق مفتاح الإجابة مع ملف Markdown، وعدم تغيّر ملف JSON.
- الترتيب العشوائي: كل امتحان يضم الأسئلة الـ100 بلا تكرار، والإجابة الصحيحة تبقى صحيحة أيًّا كان موضعها، والترتيب يختلف بين المحاولات.
- الملاحظات: ملاحظة لكل نظرية ولكل اختيار خاطئ في أسئلة المقارنات، وكلها مختصرة.
- الحفظ المحلي، والتصحيح، وتدفق الواجهة كاملًا حتى المراجعة، والتسليم التلقائي بالمؤقت.

يُبنى الموقع ويُنشر تلقائيًا على GitHub Pages عبر `.github/workflows/deploy.yml` عند كل Push إلى فرع `main` (بعد نجاح الاختبارات).
